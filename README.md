# BitChad LLC

Static corporate site for BitChad LLC, built from the Stitch `bitchad_llc_home_updated_theme` design and the Aetheric Primate system.

## Pages

- `index.html` — home, BurstClip, mission
- `careers.html`
- `privacy.html`
- `contact.html`
- `404.html`

## Local preview

```bash
python3 -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080).

## Source

The original Stitch export is in `_source/`. It is not required to serve the site.
